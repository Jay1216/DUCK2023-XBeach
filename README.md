# XBeach-Surfbeat Simulations for Duck2023

This repository provides the XBeach-Surfbeat model setup used to simulate nearshore hydrodynamics and morphodynamics at the Field Research Facility (FRF), Duck, North Carolina, during 2023.

Only the essential model input files are included. Additional simulation data are available upon request.
