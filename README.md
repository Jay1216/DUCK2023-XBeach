# XBeach-Surfbeat Simulations at Duck, NC (2023)

This repository provides the XBeach-Surfbeat model setup used to simulate nearshore hydrodynamics and beach morphological changes at the Field Research Facility (FRF), Duck, North Carolina, during 2023.

Only the essential model input files are included. Additional simulation data are available upon request.
